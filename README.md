
The Restaurant Reservation System is a simple web-based project developed using PHP, JavaScript, and CSS.
This system allows users to browse the restaurant website and make table reservations online.

The project currently focuses on the user (customer) side, providing a smooth and simple experience.

Features
User registration and login

Browse Home, About, and Contact pages

Make online table reservations

Simple and easy-to-use interface

Technologies Used
Frontend: HTML, CSS, JavaScript

Backend: PHP

Database: MySQL
